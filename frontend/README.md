# ClarityX Frontend

Modern React 18 + Vite + TypeScript + Tailwind CSS application for satellite imagery cloud detection and quality analysis.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Build output is saved to the `dist/` directory.

---

## 🌐 Deployment (Vercel / Netlify)
- **Root Directory**: `frontend`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Environment Variable**: `VITE_API_URL=https://your-backend-api-url.com`
